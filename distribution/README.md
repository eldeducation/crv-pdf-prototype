# 各自のPCで使う動画→PDF試作品

テストに通ったGitHubコミットと同じソースから作る配布版。Renderを使わず、受け取った人のPC上で起動します。配布元のPCの起動状態には依存しません。各自のPCは生成中に起動しておく必要があります。


## 導入からPDF保存まで（Windows・自分のAIと併用）

**マイクラ風の操作サイトも同梱しています。** 各自のPCでサイトを起動し、ブラウザーで動画・用途を設定できます。開発者のPCやRenderの起動状態には依存しません。起動後の`127.0.0.1`のURLは、そのPCだけで使うアドレスです。

以下はWindowsで、**ローカルファイルを読み、画像を確認し、コマンドを実行できるAI開発ツール**と併用する手順です。AIは各自のアカウントで利用します。ブラウザーだけのAIチャットにログインしても、自動では連携しません。

### 1. ZIPをダウンロードして、すべて展開する

[配布ZIPをダウンロード](https://github.com/eldeducation/crv-pdf-prototype/releases/latest/download/crv-pdf-local.zip)し、右クリックから「すべて展開」します。GitHubの「Code → Download ZIP」ではなく、この配布ZIPを使ってください。展開後、`start.cmd`と`LLM-START.md`があるフォルダを開きます。ZIPの中から直接起動しません。

### 2. 自分のAIで、展開したフォルダを開く

AI開発ツールでそのフォルダを作業場所に指定します。ファイル読み取り・画像確認・コマンド実行を使える状態にしてください。ブラウザーのチャットだけを使う場合は、下の「ブラウザーだけのAIチャットを使う場合」へ進みます。

### 3. AIに初回準備と起動を依頼する

次の文章をコピーしてAIへ渡してください。

> このフォルダのLLM-START.mdを読んで、必要な環境を準備し、試作品を起動してください。AIのAPIは使わず、解析・画像抽出・内容確認・PDF生成の処理は変更しないでください。まずはサイトを開くところまで進めてください。

Python 3.12、Node.js 22以上、FFmpeg/ffprobeなどが必要です。初回は依存関係・音声認識用ライブラリ・PDF用ブラウザーをダウンロードするため、通信・空き容量・準備時間が必要です。不足するソフトの準備はAIの案内に従います。準備が整うと、**マイクラ風のサイトがブラウザーで開きます**。開かなければ、AIに起動したPC内のURLを案内してもらってください。

### 4. サイトで動画と資料の設定をして開始する

1. 「実行方法」で**「APIを使わないテスト」**を選ぶ。APIキーの入力は不要です。
2. YouTubeリンクを入力するか、手元の動画ファイルを選ぶ。
3. 「資料の用途」で「動画に合わせる／作業手順書／セミナー要約／研修資料」を選び、詳しさ・出力言語を設定する。
4. 必要なら「すっきり」「図解多め」「写真多め」「比較で整理」と追加の希望を指定する。未指定でもデザイン重視で作成します。
5. 解説音声がない動画では該当する設定を選び、**「テストを開始する」**を押す。

「テスト」という画面名ですが、実際のPDFを生成できます。サイトで開始したあとは、同じ動画をAIから重複して開始しないでください。

### 5. 同じAIへ「続けて作成する」と依頼する

同じフォルダを開いているAIへ、次の文章を渡します。

> サイトで開始しました。LLM-START.mdに従い、ai_handoff.pyで現在の依頼を読み、画像を実際に確認して回答を返してください。追加の依頼や修正にも対応し、PDFの確認まで進めてください。新しい生成を重複して開始せず、現在の生成を続けてください。

AIが、既存の内容整理・資料作成・照合・紙面確認の依頼に順番に回答します。**「回答ファイルを待っています」は計算中ではなくAIの回答待ちです。放置しても進みません。** 途中でAIが止まったら、現在の依頼を確認して続けるよう伝えてください。サイトとAIを使える状態にし、生成中はPCをスリープさせないでください。

### 6. PDFと編集用Markdownを保存する

完了したら、サイトの**「PDFを保存」**からダウンロードします。「編集用Markdown」も保存できます。**「要確認」**と表示された資料は、指摘を確認してから使ってください。写真と説明の対応も元動画で確認します。生成物は展開先の`app/runs`にも残ります。

### 次回の起動・困ったとき

- 次回からは同じフォルダをAIで開き、**`start.cmd`をダブルクリック**して、手順4から進めます。通常は初回セットアップをやり直す必要はありません。
- 起動しない場合は、エラー画面の内容をAIへ伝え、`LLM-START.md`に従って確認してもらいます。APIキーやパスワードをチャットへ貼る必要はありません。
- YouTubeリンクを取得できない場合は、手元の動画ファイルを指定してください。取得可否は回線と配信元の制限にも依存します。
- **ブラウザーだけのAIチャットを使う場合**：同じサイトで「APIを使わないテスト」を選び、指示・画像のZIPを保存してチャットへ渡します。返ってきた回答JSONを「回答を読み込んで続ける」で取り込み、依頼ごとに繰り返します。[詳しい受け渡し手順](MANUAL-TEST.md)。チャットへのログインだけでサイトとAIが自動接続するわけではありません。
- AI側の詳しい処理手順は[LLM-START.md](LLM-START.md)にあります。AIの契約・利用枠は各自のものです。この方式では外部の動画取得サービスやAI APIキーを使いません。

配布ZIPは公開ソースと同じ生成処理を使います。研修用途の構成改善は下記のとおりです。モデル・推論設定・会話履歴が違う場合の精度や完全一致は保証できません。生成ソースの識別子はZIP内の`QUALITY-BASELINE.json`に記録します。配布物のソース一致とオフライン検証を行い、別PCでのクリーンインストールは未検証です。

## 初回準備の補足

Pythonは3.10〜3.12を対象としています。初回はPythonパッケージ・CPU音声認識用ライブラリ・PDF用Chromiumをダウンロードするため、通信とディスク容量、インストール時間が必要です。LinuxではChromium用のOSライブラリと日本語フォントも必要になる場合があります。別PC・別OSでのクリーンインストールは未検証です。

## 使い方は2通り

| 方式 | 操作 | 注意 |
| --- | --- | --- |
| APIを使わないテスト | 画面で動画と用途を選び、指示・画像をLLMへ渡し、回答JSONを取り込む | 既存チャットの利用枠を使う。サイトとLLMが自動接続するわけではない。回答待ちは放置しても進まない |
| APIで生成 | 自分のOpenRouterまたはAnthropicキーを画面に入力し、取得されたモデル一覧から選ぶ | API料金は自分のキーに発生。直接OpenAIキーには未対応 |

一般のChatGPTやClaudeのチャットでも、指示・画像のZIPを渡して回答JSONを受け取る方法で併用できます。ファイルの数・サイズ・利用枠には各サービス側の制約があります。APIなしモードのモデルは回答を書いたチャットのモデルで、画面のAPIモデル選択は適用されません。

用途は「動画に合わせる／作業手順書／セミナー要約／研修資料」。デザイン重視を標準として、すっきり・図解多め・写真多め・比較で整理を組み合わせられます。

詳しい受け渡しは [MANUAL-TEST.md](MANUAL-TEST.md)、LLM向けの案内は [LLM-START.md](LLM-START.md) を参照してください。

ローカルファイルを扱えるAIでは、`ai_handoff.py`で開始・依頼の確認・回答の提出・成果物の確認を行えます。毎回ZIPを取り込む必要はありません。AI自体は利用者が開いているものを使い、補助コマンドがAIへログインしたりAPIを呼んだりすることはありません。

## 生成処理の維持

この配布版は、公開ソースと同じ生成処理を含みます。`QUALITY-BASELINE.json`で実際に含めたソースのハッシュを確認できます。ハッシュは品質の点数や、過去の版からプログラムが変わらないという保証ではありません。別のAIモデルや会話履歴でも同じ精度になることを保証するものではないため、同じモデル・推論設定・動画・用途で比較してください。

「研修資料」では、学習目標・全体像・動画の具体例、確認問題と教材用の架空の応用練習、後の別ページの解答、適用先で相談・記入する持ち帰り欄を構成します。`training_plan`と本文の原文・ページ・出典の対応を提出時に検査し、解答の根拠や写真の有用性は既存の内容照合でも確認します。写真の枚数は固定せず、必要な表示や動作の理解に役立つものを選びます。

別のAI工程は追加していません。既存の動画解析・根拠写真・安全性・紙面の検査は維持し、他用途に研修構成は強制しません。既存PDFは変更しません。旧版の途中保存は仕様が変わるため、そのまま再開できません。新規生成か、内容確認済み資料の「内容を保って仕上がりを変更」を使ってください。改善後の実モデルによる品質・費用は未測定です。

## 保管・共有

- このZIPにはAPIキー・利用者の動画・生成済み資料・会話履歴・個人PCのパス・ブラウザーCookieを含めません。初回セットアップが各PCのパスを作ります。
- 起動時にAIキーの環境変数を引き継がず、app/.envがある場合は起動しません。キーは画面で入力し、終了時は接続解除してください。
- 起動先は127.0.0.1だけです。公開トンネルや外部からのアクセスは開始しません。起動URLは他人のPCでは使えません。各自が展開して起動してください。
- 動画や生成物は各PCのapp/uploads、app/runs、app/workに残ります。使用済みフォルダ全体をそのまま再配布しないでください。
- LLMに渡す画像・文字起こしは、そのLLMサービスへ送られます。非公開動画の共有可否を確認し、必要なら外部検索をオフにしてください。
- 元動画と照合して使ってください。YouTube/Xの取得可否は各PCの回線と配信元の制限にも依存し、この版でも取得成功を保証しません。個人ログイン情報は自動取得しません。

## 配布物の検証範囲

コミットとソース識別子はapp/build-info.jsonと画面下部、全ファイルのハッシュはMANIFEST.jsonで確認できます。配布ZIPは同じmainでテスト後に自動作成され、ソースの一致と秘密ファイルの除外を検査します。別PCでのインストール成功、全動画・全モデルのPDF品質、独立した安全性監査を保証するものではありません。公開の比較PDFはこのZIPに含めません。

- [公開ソース](https://github.com/eldeducation/crv-pdf-prototype)
- [13題材・22種類の見本](https://crv-pdf-video-showcase.eldesign-8040.chatgpt.site/)
- [Opus比較用の元PDF](https://github.com/eldeducation/crv-pdf-prototype/blob/main/OPUS-REFERENCES.md)

外部依存はインストール時に取得し、それぞれのライセンスが適用されます。CRVはMIT、FFmpeg等は各配布元の条件を確認してください。第三者依存や動画そのものは同梱していません。

## 版の確認

画面下部のバージョンとapp/build-info.jsonのrevisionを照合してください。設定やソースを自分で変更した場合、配布時のコミットではなくlocalと新しいソース識別子を表示する場合があります。更新は別フォルダへ展開し、必要なPDFを先に保存してください。
