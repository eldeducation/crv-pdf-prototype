## 比較条件

- 保存済みソースのハッシュが、Opus版作成時の記録と一致している。
- 最初の編集依頼は、画像を含むメッセージ全体の一致を確認した。同じ動画・96枚の基礎画像・文字起こし・12項目の内容案・既存の調査を利用した。
- 過去のPDF本文や紙面を新しいモデルの入力には使っていない。
- 共通の内容案を使うため、動画を独立に理解するモデル能力ではなく、資料の編集・構成・検証の比較である。
- 費用上限のみOpus $6.50 / Sol $3.85。Solは上限に当たらずに完了した。highは各モデルの設定値で、内部の思考量を同一にした意味ではない。
- ページ数を固定する指示ではないため、文章・写真の量の違いも費用差に含まれる。1回ずつの結果から一般的なモデル優劣は断定しない。

## 内容・読みやすさの所見

**Opusの強み：背景と具体例が豊富。** 冒頭の全体表、数値一覧、YCの規模拡大の話、ChatGPTの成立過程などを詳しく残しており、講義を振り返る資料に向く。主張・例・条件・不確実性を繰り返し示している。一方、本文や写真が多く、通読する量は増える。

**Solの強み：要点と留保を短く追いやすい。** 8ページにまとめ、100人規模の評価、小規模で既に機能しているという拡大条件、GPU数と目標時期、予想の反証の扱いなど主要な論点を維持している。写真の使用回数は30から17に減った。目標と達成の違い、推測不足と誤りの違いなど、読み違いを防ぐ注意が目立つ。一方、YCの議論などは短く、細部の説明量はOpusに及ばない。

**正確性で明確な勝者とはしない。** 最初の内容照合では、Opusは14:51の写真キャプション、Solは利用状況について根拠のない「日中」という限定を、それぞれ1か所修正した。最終版は両方とも同じ仕組みの内容照合を通過したが、講演者の主張自体を第三者が検証した結果ではない。

今回の用途が短時間で読めるセミナー要約ならSol、講義の背景と具体例を多く残すならOpusを選ぶ根拠になる。モデル全般の正確さの順位を決める比較ではない。
