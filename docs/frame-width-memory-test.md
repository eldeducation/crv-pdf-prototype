# 動画準備の画像横幅を比較する

初期抽出の横幅は従来どおり1280pxです。環境変数 `VIDEO_PDF_FRAME_WIDTH=640` で640pxに切り替えられます。RenderではEnvironmentにこの変数を指定してからデプロイします。1280に戻すか変数を削除すると元に戻ります。セッション用サーバーにも設定を引き継ぎます。

Pythonでは `Config(frame_width=640)`、CLIでは `--frame-width 640` も指定できます。adaptive、grid、最大96枚、追加画像確認時の解像度は変更しません。640pxは横幅であり、縦640pxの指定ではありません。

比較は同じ動画を新しいrunで準備し、APIなし・文字起こし省略・外部検索なしにします。AIの回答待ちまで到達した時点を動画準備完了とし、AIへの回答・PDF生成はこの比較に含めません。既存解析の再利用や途中再開で比較しないでください。

`resource_sample` はサンプリング値なので、記録最大値は瞬間的ピークの保証ではありません。`server_boot`、RenderのOOMイベント、抽出ログ、準備完了の有無を併せて確認します。ローカルのプロセスメモリとRenderコンテナ全体のメモリは測定範囲が異なります。640px化だけで512MB以内になるとは保証しません。
